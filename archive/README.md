## Publication hygiene

- Local Windows profile path prefixes in copied text files were replaced with `$env:USERPROFILE`; source files in the original workspace were not changed.
- The `.nexus-outbox` directory was excluded because it contains private agent-memory receipts rather than project documentation.
- The archived Git bundle was excluded because it is a binary repository artifact, not documentation.
- A scan was performed for common credential formats and personal email addresses before publication. No such matches were found in the selected source files. This is a hygiene check, not a guarantee that every possible sensitive value can be detected automatically.
- The published material is a historical working record. Readers should treat claims about status as time-bound and verify against the linked service repository.
